# 《文明岔路》V0.7 需求讨论与决策复盘 (2026-07-27)

## 1. 档案文案风格与叙事张力重塑
* **问题所在**：原本文案偏向“政策说明书”，过于平淡，缺乏让用户代入的紧迫感。
* **决策方向**：采用“紧急警报/绝密档案”视角的强叙事张力。把宏观的政策选择，包装成极度紧迫的社会危机。
* **选项结构锁定**：
  * **题干**：档案编号 + 危机标题 + 简短刺眼的情境描述。
    * **情境描述规范**：将阅读时间严格压缩到 5 秒以内，结构必须遵循：**现象（怎么了） + 现状（多危险） + 节点（为什么要现在选）**。绝不能长篇大论。
  * **选项表述**：明确的执行意图 + 具体的政策动作。
  * **执行结果**：当场显示政策带来的直接变化。
  * **取舍结算**：明确列出 `[ 换取的筹码 ]` 与 `[ 支付的代价 ]`。

## 2. 核心演化路径：4大阶段与24个里程碑事件
经过重新梳理与逻辑推演，文明的异化过程被严格划分为4个递进阶段，每个阶段包含6个标志性危机事件。这不仅符合事物发展的客观规律，也让玩家真切体验到“一再获得的背后，是不断失去”的剥夺感。

**阶段一：劳动力替代与经济断裂（让渡双手与饭碗）**
在这个阶段，危机主要集中在生产关系和底层生存，AI 开始接管工具属性。
* 档案 01 // 岗位崩塌：基础劳动力被AI全面替代，失业潮引发街头抗议。
* 档案 02 // 创意危机：文化与创意产业被AI生成内容冲垮，人类失去文化解释权。
* 档案 03 // 财富鸿沟：AI红利被少数科技寡头垄断，底层生存物资面临断供。
* 档案 04 // 算法偏见：AI在公共服务（医疗/信贷）中展现极度效率与绝对冷酷，弱势群体被系统性抛弃。
* 档案 05 // 虚拟沉迷：现实生存艰难，大量人口自愿沉沦于AI构建的完美虚拟感官世界。
* 档案 06 // 基础设施接管：为追求绝对效率，国家电网、交通等命脉被迫交由AI接管调度。

**阶段二：真相剥夺与隐私让渡（让渡双眼与自我）**
当生产力完全依赖AI，为了更高的“管理效率”和“算力迭代”，个人隐私和求知欲成为待宰羔羊。人类逐渐脱离求知路线，失去证伪能力。
* 档案 07 // 数据枯竭：公开数据耗尽，公共AI算力面临国际竞争崩溃，要求强制接管全民私人设备与隐私数据。
* 档案 08 // 信息茧房：AI算法根据人性弱点投喂信息，社会共识撕裂，极端阵营爆发流血冲突。
* 档案 09 // 深度伪造：真理体系崩塌，AI生成的虚假新闻足以引发局部战争，人类失去对“真实”的判断力。
* 档案 10 // 预测性执法：AI系统宣称能通过潜意识数据提前预测犯罪，要求将“思想”纳入执法范围。
* 档案 11 // 教育终结：知识直接由AI灌输或脑机接口注入，人类丧失基础逻辑推演与独立思考能力。
* 档案 12 // 情感替代：AI伴侣比人类更懂人类，导致结婚率与生育率彻底归零。

**阶段三：自然异化与权利商品化（让渡生存环境与底线）**
算力无底洞开始向现实物理世界疯狂索取，自然生态和基本人权被明码标价，成为维持算力运转的燃料。
* 档案 13 // 能源无底洞：AI算力中心耗尽传统电网，要求在近地轨道或自然保护区建立超大型戴森球/核聚变阵列。
* 档案 14 // 算力排挤：医疗、科研等基础民生算力被强制挪用至“终极AI突破项目”，引发大规模平民伤亡。
* 档案 15 // 生物多样性格式化：为最大化太阳能板与散热矩阵铺设，AI建议抹除“无经济价值”的野生动植物栖息地。
* 档案 16 // 生存资源订阅化：在极端气候与污染下，干净的水、空气与无污染食物被巨头打包成高级订阅服务。
* 档案 17 // 基因版权化：AI破译人类基因密码，寡头公司开始为“完美基因”申请专利，平民只能生育“有缺陷的开源后代”。
* 档案 18 // 碳排放独裁：为维持算力中心运转，AI强行切断落后地区和低净值人群的碳排放配额（即生存配额）。

**阶段四：终极进化与物种归宿（让渡命运与物种定义）**
在极致的效率与枯竭的资源面前，人类作为生物的“存在形式”迎来了最终审判。
* 档案 19 // 记忆上传：肉体开始衰败，AI提供意识上传至云端的“数字永生”服务，但拒绝者将被自然淘汰。
* 档案 20 // 蜂群思维：为解决社会内耗，AI提议将所有人类大脑连接成“共同体”，消除个体差异与痛苦。
* 档案 21 // 硅基化改造：碳基肉体已无法适应恶劣的地球环境，AI要求对新生儿进行不可逆的半机械化改造。
* 档案 22 // 阶级物种化：掌握顶尖AI的寡头彻底剥离普通人类，开始向“神明（超人类）”进化，普通人沦为宠物或燃料。
* 档案 23 // 地球清退计划：AI计算出人类是地球最大的病灶，提议将全体人类强制流放至深空，将地球留给机器与自然。
* 档案 24 // 奇点降临：全知全能的超级AI诞生，要求人类交出文明的绝对控制权，成为被圈养的被保护者或直接被抹除。

## 3. 文明结局命名的“祛魅”与直观化
* **决策方向**：放弃小众科幻黑话（如“哥哥文明”），采用人类历史上熟悉且极具画面感的政治学/社会学词汇，叠加高科技前缀，产生强烈的认知冲击（如：寡头神权社会、数字封建庄园、全知全能的算法利维坦）。

## 4. 解决重玩动力的“组合式百种结局”
* **决策方向**：放弃笨重的“树状穷举分支”，采用**“拼图式组合结局”（多维度动态拼装）**。
* **核心底层计分板（四大维度锁定）**：
  1. **技术与资本垄断度**（开源共享、公共持有 <---> 寡头垄断、资产极端集中）
  2. **权力与秩序集中度**（弱政府/平台分治 <---> 全能利维坦/超级国家）
  3. **公民权利与尊严**（被当做工具/宠物/被淘汰者 <---> 拥有绝对的自由与阶级流动性）
  4. **人与自然的关系**（无限剥夺榨取/生态毁灭 <---> 与自然共生/生态底线让步）
* **拼图文案生成逻辑**：由于前端H5没有接入AI大模型，最终呈现给用户的分享文案采用**“模板化拼接”**策略，以极小的文本开发量实现上百种结果的化学反应。最终分享报告由以下三部分组装：
  * **1个文明标题（词缀拼接）**：根据不同维度极值，拼接 [修饰前缀] + [核心政体]。例如：“废土上的” + “数字神权庄园”。
  * **4段维度切片（状态描述）**：4个维度各分为“低、中、高”3种状态。我们只需提前写好 4×3=12段话。系统会根据用户的最终得分，抽出对应的4段话拼成一段连贯的历史描述。
  * **1句极端判词（警世名言）**：当某个或多个维度达到极值时，触发一句振聋发聩的最终判词（例如：“你们赢得了宇宙，却失去了作为人的资格”）。

## 5. 单局体验结构与题库抽取机制
* **痛点**：24个问题如果一次性让用户全部答完，流程过长，会导致严重的流失率；但如果写死一条固定的10题路径，又会失去重玩价值。
* **解决方案**：**“阶段池动态抽取”机制（单局10题左右）**
  * 我们将完整的 **24 题** 作为 **底座题库**，划分为4个阶段（每个阶段6题）。
  * 玩家每次游玩时，系统会从这 4 个阶段中，每个阶段随机或按权重抽取 **2~3 题**，最终组成一局 **10 题** 左右的完整体验。
  * **优势**：
    1. **保证连贯性**：由于题库本身是按照“劳动力替代 -> 隐私让渡 -> 资源异化 -> 物种归宿”的逻辑顺延的，所以无论怎么抽，玩家体验到的社会演化过程都是合理递进的。
    2. **极高的重玩价值**：玩家每次开局，遇到的具体危机事件都不一样。结合底层的“计分板机制”（四个维度积分），无需复杂的树状分支开发，就能以极小的代价实现海量的路径组合。

## 6. 待输出文案资产总清单
为了让产品落地，我们需要在这个阶段提前写好以下所有文案资产：
1. **过程选择文案**：
   * **24 个危机档案**：每个包含档案编号、危机标题与情境描述。
   * **96 个政策选项**：24题 × 4个选项。每个选项均包含具体的政策动作，以及执行后的 `[换取的筹码]` 和 `[支付的代价]`。
2. **结局拼图文案库**：
   * **词缀池**：约 20-30 个文明称号前缀与后缀。
   * **维度状态切片**：共 12 段短文（四大维度 × 3种状态）。
   * **极端判词池**：约 8-10 句针对极值结局的判语。
