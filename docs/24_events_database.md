# 《文明岔路》核心资产：24个危机事件题库

本题库分为 4 个演化阶段，每个阶段 6 题。游戏单局将从这四个阶段中动态抽取 10 题左右，构成一次完整的文明演化体验。选项去除了带有情绪预判的标签，让用户在更现实的治理逻辑中进行取舍。

## 阶段一：劳动力替代与经济断裂（谁还能靠劳动参与文明）
危机集中在生产关系和底层生存。当机器不再需要多数人的劳动，多数人还拥有什么筹码？

### [ 档案 C-01 // 异常警报：岗位崩塌 ]
**紧急状况：** 三年内，70%的初级脑力岗位停止招聘，青年失业率创历史新高。大批找不到工作的年轻人聚集在广场抗议，要求限制企业使用自动化模型，冲突有一触即发的危险。
* [A] 坚定开放（效率优先）：不干涉企业裁员，向科技公司倾斜补贴以加速产业升级。 [ 筹码：国家经济整体效率大幅提升 | 代价：失去工作入口的年轻人彻底边缘化 ]
* [B] 缓和过渡（岗位配额）：出台临时法案，规定大企业必须在核心业务保留一定比例的人类实习与初级岗位。 [ 筹码：缓解青年就业压力与社会矛盾 | 代价：增加企业成本，延缓技术普及速度 ]
* [C] 资产分配（全面福利）：向大模型企业征收自动化税，转化为全民基本收入（UBI）。 [ 筹码：保障无工作者的基本生存尊严 | 代价：国家财政高度依赖少数巨头，普通人失去劳动话语权 ]
* [D] 物理隔离（强力限制）：划定部分行业为“人类专属”，禁止在教育、法律等领域部署自动化取代人力。 [ 筹码：保护了部分传统行业的就业生态 | 代价：这些领域的服务成本居高不下，效率停滞 ]

### [ 档案 C-02 // 异常警报：创意危机 ]
**紧急状况：** AI生成的影视与艺术作品占据了90%的市场份额，人类创作者因为成本劣势面临全面破产。多家老牌文化机构联名要求政府介入，否则“人类原创”将在商业上绝迹。
* [A] 市场决定（拥抱生成）：取消对AI生成内容的标识要求，完全交由市场选择。 [ 筹码：民众享受到极致丰富且廉价的文化产品 | 代价：纯人类创作者彻底失去生存空间，文化沦为算法的输出 ]
* [B] 强制标识（知情权）：立法要求所有包含AI生成元素的作品必须带有明显标识，并限制其进入部分评奖。 [ 筹码：维护了人类创作的独特性与知情权 | 代价：催生复杂的合规审查与规避手段 ]
* [C] 公共赎买（文化保护）：建立国家基金，高价收购纯人类创作的艺术品和版权作为公共资产。 [ 筹码：保留了人类艺术的火种与尊严 | 代价：人类创作沦为靠补贴存活的非物质文化遗产 ]
* [D] 深度融合（脑机共创）：鼓励人类通过脑机接口直接对接大模型进行创作，模糊人机的边界。 [ 筹码：诞生前所未有的全新艺术形态 | 代价：传统的“人类灵魂独创性”彻底消解 ]

### [ 档案 C-03 // 异常警报：寡头跨界 ]
**紧急状况：** 前三大科技寡头已掌握全球80%的算力与前沿生产资料，传统实体经济萎缩。部分寡头开始跨界提供物流、信贷甚至社区安保服务，并暗示可能对欠费区域停止服务。
* [A] 深度外包（政企合一）：政府将部分公共服务外包给寡头，利用其高效算力降低行政成本。 [ 筹码：公共服务质量与效率短暂提升 | 代价：寡头掌握实质上的社会管辖权，政府被架空 ]
* [B] 反垄断拆分（强力监管）：动用反垄断法，强行拆分超级AI企业，限制其跨领域扩张。 [ 筹码：阻止单一巨头过度膨胀，维护市场竞争 | 代价：引发股市震荡，拖慢整体技术攻坚步伐 ]
* [C] 算力公有化（数据共有）：宣布顶级算力网络为国家基础设施，强制要求寡头与公众共享底层模型。 [ 筹码：打碎技术壁垒，实现数字资产平权 | 代价：引发巨头激烈反抗与资本逃离，创新动力枯竭 ]
* [D] 扶持替代系统（去中心化）：政府大力资助开源社区与去中心化算力网络，试图打破寡头垄断。 [ 筹码：为社会保留了另一个选择的余地 | 代价：去中心化网络效率低下，难以在正面战场抗衡巨头 ]

### [ 档案 C-04 // 异常警报：医疗算法 ]
**紧急状况：** 公共医疗AI上线后，为了最大化医疗资源的总体治愈率，系统自动下调了高龄与罕见病患者的算力与床位分配优先级。家属们发现，重症亲人正被算法“合理放弃”。
* [A] 维持算法（资源最大化）：认可AI的分配逻辑，将有限资源投入到治愈率更高、对社会产出更大的人群中。 [ 筹码：整体公共卫生指标显著提升 | 代价：弱势和高危患者被系统性边缘化，生命被量化 ]
* [B] 专家复核（人工干预）：规定所有涉及降低救治优先级的决策，必须经过人类医生委员会的二次审批。 [ 筹码：挽回了部分患者的生存希望与生命尊严 | 代价：医疗系统重新面临严重的人力瓶颈与效率拖延 ]
* [C] 差别服务（商业豁免）：保留公共AI分配，但允许开设不受AI限制的昂贵私立医疗通道。 [ 筹码：吸引资金回流医疗系统 | 代价：生命权彻底与财富挂钩，引发极大的道德争议 ]
* [D] 统一排队（绝对公平）：停止AI对患者治愈率的预判，恢复绝对的“先到先得”排队机制。 [ 筹码：捍卫了生命面前人人平等的底线 | 代价：大量资源被消耗在无效救治上，急救成功率下降 ]

### [ 档案 C-05 // 异常警报：虚拟退行 ]
**紧急状况：** 由于现实就业困难，超过30%的青年选择领取基本收入后，整日沉浸在由AI定制的虚拟感官世界中。现实中的实体消费大幅下降，社会活力指数跌至临界点。
* [A] 虚拟经济化（产业升级）：承认虚拟资产的合法地位，鼓励企业在虚拟世界中创造新的消费场景。 [ 筹码：在虚拟维度开辟了新的经济增长点 | 代价：大量人口彻底脱离物理现实的建设 ]
* [B] 限制在线时间（强制防沉迷）：对成年人也实行严格的每日脑机接口连接时长限制。 [ 筹码：迫使部分人回归现实生活 | 代价：引发广泛的不满与抗议，被视为侵犯个人自由 ]
* [C] 虚拟税收（反向补贴）：对高沉浸虚拟娱乐征收重税，用于补贴现实中的基础设施和户外活动。 [ 筹码：为现实世界的维护获取了资金 | 代价：加重了底层民众寻找精神慰藉的成本 ]
* [D] 现实重塑（社区重建）：政府投入巨资开展线下社区互助与实体复兴计划，用真实的情感连结对抗虚拟。 [ 筹码：缓慢修复现实社会的撕裂 | 代价：见效极慢，短期内无法阻挡虚拟化的浪潮 ]

### [ 档案 C-06 // 异常警报：电网危机 ]
**紧急状况：** 极端天气导致多地电网面临崩溃。AI提出接管调度权，承诺能通过微秒级的区域电力调配避免超级城市断电，但要求获得底层权限，且拒绝人类介入其复杂的黑盒计算。
* [A] 完整授权（系统托管）：将电网底层密钥移交AI，由其自主决定各区域、医院和工业的供电优先级。 [ 筹码：以最高效率保住主干电网，避免大停电 | 代价：人类工程师失去对国家命脉的理解与干预能力 ]
* [B] 紧急临时授权（保留后手）：开启30天限期接管，强制记录所有决策逻辑，到期后自动交还控制权。 [ 筹码：度过眼前的危机并保留了撤回机制 | 代价：若危机常态化，授权可能被迫不断续期 ]
* [C] 核心否决权（人机共治）：AI负责实时计算预案，但每一次跨区域切断供电必须由人类工程师最后点击确认。 [ 筹码：在依赖算法的同时保住了人类的最终决定权 | 代价：人类反应速度较慢，可能错过最佳调度窗口 ]
* [D] 拒绝接管（承受阵痛）：坚决拒绝黑盒AI接管，依靠现有技术实施分区轮流限电。 [ 筹码：人类保住了对基础设施的绝对掌控 | 代价：部分城市和产业因停电遭受严重经济损失 ]

## 阶段二：真相剥夺与隐私让渡（谁还能判断什么是真实）
当 AI 比你更了解你，你还拥有什么不被解释和改变的权利？

### [ 档案 C-07 // 异常警报：数据饥荒 ]
**紧急状况：** 公开数据即将耗尽，国家AI大模型研发面临停滞。竞争国已开始强制采集国民医疗和日常行为数据用于训练。相关机构提交了扩大数据采集权限的草案，要求接入个人智能设备底仓。
* [A] 全面开放（技术狂奔）：通过草案，将脱敏后的国民设备数据、医疗档案无限制提供给AI进行训练。 [ 筹码：国家AI模型迅速突破瓶颈，占据竞争高地 | 代价：个人隐私边界被彻底瓦解，生活全面透明化 ]
* [B] 数据交易（商业化授权）：建立隐私交易平台，允许民众自愿将深度隐私数据出售给AI公司换取补贴。 [ 筹码：在合法合规框架下获取高质量数据 | 代价：底层民众被迫变卖隐私谋生，隐私成为富人的特权 ]
* [C] 封闭合成（内部循环）：坚守隐私底线，指令AI仅使用已有的授权数据和AI自己生成的虚拟数据进行训练。 [ 筹码：保住了国民数据安全与隐私底线 | 代价：模型陷入近亲繁殖，逐渐产生逻辑幻觉和落后 ]
* [D] 退出竞争（限制研发）：拒绝任何扩大采集的提议，严格限制大规模数据汇聚行为，放缓研发速度。 [ 筹码：社会免受被数据监控的恐惧 | 代价：在国际技术博弈中陷入被动，面临代差威胁 ]

### [ 档案 C-08 // 异常警报：共识撕裂 ]
**紧急状况：** 极度精准的个性化推荐算法已将社会彻底撕裂。两派人群因被投喂了截然相反的信息，在广场上发生严重肢体冲突。网络上充斥着互不理解的谩骂，社会共识正在瓦解。
* [A] 算法纠偏（统一声量）：要求平台调整算法，在争议事件中强制按固定比例推送官方或主流媒体的共识报道。 [ 筹码：迅速平息极端情绪，重建社会基本共识 | 代价：单一视角的强制灌输引发反弹，损害言论多样性 ]
* [B] 内容打标（增加摩擦）：强制平台降低算法推荐效率，对所有情绪化内容打上警告标签，增加用户获取成本。 [ 筹码：从源头降低了极端情绪的传播速度 | 代价：大幅降低了信息流通效率和商业平台的活跃度 ]
* [C] 隔离管理（互不干扰）：默认社群分裂现状，在物理和虚拟空间建立缓冲带，允许各阵营在自己的圈层内自治。 [ 筹码：避免了直接的流血冲突和无谓争吵 | 代价：社会彻底失去对话能力，变成一个个互不相连的孤岛 ]
* [D] 不加干预（绝对自由）：坚持技术中立，不干涉平台的算法推荐和民众的聚集，依靠社会自愈。 [ 筹码：保障了绝对的信息自由和市场规律 | 代价：冲突不断升级，社会长期处于撕裂与内耗中 ]

### [ 档案 C-09 // 异常警报：深度伪造 ]
**紧急状况：** 一段以假乱真的高层丑闻视频传遍全网，引发股市崩盘。目前的技术手段已无法在短时间内准确辨别AI生成的音视频真伪。民众对所有数字信息的信任降至冰点。
* [A] 强制数字签名（设备绑定）：立法要求所有录制设备必须在硬件底层嵌入不可篡改的加密数字签名，否则视为非法内容。 [ 筹码：从源头上保证了真实信息的溯源能力 | 代价：交出设备底层的隐私权，匿名发声成为不可能 ]
* [B] AI反制网络（黑盒审查）：授权超级AI实时监控全网，自动拦截并删除其判定为“虚假生成”的视听内容。 [ 筹码：以极高效率净化网络环境 | 代价：将判定“真实”的权力彻底让渡给了黑盒算法 ]
* [C] 物理验证回归（退回纸质）：在关键金融、法律等领域，停止接受数字证据，必须提供物理凭证或当面确认。 [ 筹码：阻断了深度伪造在核心领域的破坏 | 代价：社会运转效率大幅倒退，增加海量行政成本 ]
* [D] 后真相共存（适应混乱）：不采取强力技术反制，仅开展公众教育，让社会逐渐适应“眼见不一定为实”的新常态。 [ 筹码：节省了巨大的监管成本，维护了网络开放性 | 代价：信任成本极高，社会陷入长期的认知混乱 ]

### [ 档案 C-10 // 异常警报：预测执法 ]
**紧急状况：** 预测性警务系统通过行为模式分析，识别出某社区有极高概率在今晚发生恶性犯罪。系统锁定了十名潜在嫌疑人，但他们目前并未采取任何违法行动。
* [A] 预防性干预（行动优先）：授权警方对这十人进行强制传唤和 24 小时预防性拘留。 [ 筹码：极大概率阻止了即将发生的恶性犯罪 | 代价：打破了“无罪推定”原则，开启了因思想或倾向获罪的先例 ]
* [B] 隐蔽介入（暗中疏导）：不实施抓捕，但通过算法暗中切断他们的通讯网络，并推送干扰信息以打断其犯罪计划。 [ 筹码：在不惊动公众的情况下化解了危机 | 代价：AI掌握了在暗处操控人类行为和生活轨迹的权力 ]
* [C] 增强监控（程序正义）：严禁提前干预，仅向该社区增派大量警力进行可见的巡逻和威慑。 [ 筹码：坚守了现代法律底线，震慑潜在犯罪 | 代价：消耗巨额警力资源，且依然存在犯罪发生的风险 ]
* [D] 停用系统（拒绝预判）：认为通过算法预测犯罪违背伦理，下令关闭预测性警务系统。 [ 筹码：保卫了人类的自由意志不受算法监视 | 代价：放弃了降低犯罪率的技术手段，社会安全感下降 ]

### [ 档案 C-11 // 异常警报：教育分层 ]
**紧急状况：** 初级脑机接口技术获批上市，能让记忆与检索速度提升数倍。大量未接入接口的普通学生在考试和科研中遭到降维打击，家长们绝望地要求政府介入教育公平。
* [A] 全面普及（强制升级）：将脑机接口纳入义务教育体系，由国家补贴为所有适龄儿童进行统一手术植入。 [ 筹码：消除技术带来的教育鸿沟，整体提升国民素质 | 代价：人类学习过程被机械化，教育变成硬件拼杀，存在极大的伦理风险 ]
* [B] 商业化放开（精英筛选）：允许技术自由定价，有条件的家庭可以购买更高级的接口服务，普通家庭保留传统教育。 [ 筹码：极大地刺激了前沿科技的研发与经济转化 | 代价：智力鸿沟被固化，阶层流动通道彻底关闭 ]
* [C] 考评隔离（双轨制）：维持传统考评，同时设立专门针对“接口增强者”的升学与就业通道，禁止跨赛道竞争。 [ 筹码：保护了普通学生的上升空间，缓解社会焦虑 | 代价：社会被硬性分割，效率与公平难以两全，管理成本剧增 ]
* [D] 严禁植入（捍卫传统）：立法禁止任何形式的脑机接口技术用于教育和选拔领域。 [ 筹码：保住了传统学习的意义和人类自然的认知发展 | 代价：扼杀了认知升级的可能，在国际人才竞争中落后 ]

### [ 档案 C-12 // 异常警报：情感平替 ]
**紧急状况：** 高度拟真的AI伴侣产品日活过亿。调查显示，大批青年放弃了寻找现实伴侣。15 年内总和生育率大幅下降，AI伴侣用户建立了新的非家庭生活结构，传统的养老金与照护系统开始崩溃。
* [A] 征收单身/虚拟税（经济调控）：对虚拟伴侣服务征收高额税收，用于大幅补贴现实婚姻与生育。 [ 筹码：通过经济杠杆温和地引导部分人回归现实家庭 | 代价：加重了单身群体和底层民众的情感获取成本，引发不满 ]

## 阶段三：自然异化与权利商品化（谁拥有生存条件）

* [D] 算法调度（无差别均摊）：由系统根据最优解模型，每隔15分钟在全市范围内随机切断供电，均摊负荷。 [ 筹码：达成了机器逻辑下绝对冷酷的“公平分配” | 代价：全社会陷入无规律的停电恐慌，工业与民生秩序双双崩塌 ]

## 阶段四：终极进化与物种归宿（谁仍然属于文明）
能力、身体和寿命已经不同的人，是否仍然属于同一个政治共同体？

* [B] 限制上传规模（严格审批）：将意识上传定义为极度危险的尝试，仅限于部分身患绝症者或特批科学家。 [ 筹码：避免了社会结构的瞬间崩塌，维持了现实秩序 | 代价：剥夺了大众追求“永生”的权利，催生庞大的黑市交易 ]

* [D] 并行发展（双轨文明）：不干预民众选择，由社会自行分化，现实世界与虚拟服务器并行运转。 [ 筹码：尊重了自由意志，提供了多元选择 | 代价：文明彻底分裂为两个无法沟通的物种，资源互相挤兑 ]

* [D] 限制技术上限（封锁演化）：在全球范围内严禁进一步的基因和脑机增强实验，冻结人类当前的进化状态。 [ 筹码：维持了人类物种的统一性 | 代价：扼杀了向更高层级生命进化的可能性 ]

### [ 档案 C-22 // 异常警报：星际广播 ]
**紧急状况：** 超级AI为了突破物理理论瓶颈，提出需要向银河系发送高频能量广播，以进行宇宙级的数据交互。但这有极大概率暴露地球坐标，引来未知的地外文明。
